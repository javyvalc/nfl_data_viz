# NFL Data Viz

## App Link

[NFL_Data_Viz Posit App](https://javyvalc-nfl-data-viz.share.connect.posit.cloud)

### Project Background

I wanted to learn the nflverse and ffverse packages to answer my own analytical questions for fantasy football.
This repo is a standalone dashboard to quickly explore the data for NFL games, players and plays. It's my first project in R Shiny that is publicly hosted using Posit Connect Cloud.
